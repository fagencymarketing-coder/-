# База email бухгалтеров — Алтайский край и Республика Алтай

Сегментированная B2B-база email, собранная через Apify.

## Результат

| Показатель | Значение |
|---|---|
| Всего уникальных email | 93 |
| Уникальных организаций | 82 |
| Сегмент A — частные бухгалтеры | 6 |
| Сегмент B — бухгалтерии компаний | 6 |
| Сегмент C — бухгалтерские компании | 81 |
| Твёрдое ядро (ядро + осн. контакт) | 68 |

География: Барнаул 67, Бийск 17, Горно-Алтайск 7, Новоалтайск 1, Майма 1.

## Сегменты

- **A** — частные бухгалтеры (физлица, ИП, фрилансеры), email принадлежит конкретному человеку
- **B** — бухгалтерии компаний (штатные бухгалтеры, главбухи, финотделы), маркеры
  `buh@`, `glavbuh@`, `glbuh@`, `buhgalteria@`, `accounting@`, `finance@`
  либо явная подпись роли
- **C** — бухгалтерские компании на аутсорсе, аудиторские и консалтинговые фирмы,
  франчайзи 1С

## Пайплайн

1. **Сбор организаций** — Apify actor `zen-studio/2gis-places-scraper-api`.
   Для C — рубрики бухучёта и аудита по городам. Для B — широкие рубрики
   (производство, ЖКХ, юруслуги, строительство, торговля, транспорт,
   пищепром, сельхоз, медцентры, энергетика) с фильтром «есть сайт».
2. **Добыча email с сайтов** — Apify actor `vdrmota/contact-info-scraper`
   с `maxDepth: 1` (заходит на страницы контактов, где и живут адреса
   бухгалтерии). Даёт втрое больше адресов, чем одна выдача 2GIS.
3. **Классификация и очистка** — `build_full.py`: раскладка по A/B/C,
   дедупликация по email, разметка качества, стоп-лист, выгрузка в xlsx.

## Правила отбора

- Email берётся только в явном виде с открытой страницы. Конструирование
  по маске (`info@` + домен) запрещено.
- Каждая запись имеет прямую ссылку на источник и попадает ровно в один сегмент.
- При сомнении — пометка `(?)` и наиболее вероятный сегмент.
- Исключаются: ФНС и органы власти, федеральные сервисы без местного офиса,
  записи без email.
- Дедупликация по email, домену и названию организации.

## Колонки разметки

- **Качество**: `ядро` / `спорная` — отделяет твёрдые записи от требующих
  ручной проверки.
- **Осн. контакт**: `да` / `нет` — первый адрес организации против
  последующих адресов той же компании.

Срезы: вся база 93, без спорных 76, твёрдое ядро 68.

## Что осталось за рамками

- **Славгород, Камень-на-Оби, Алейск** не покрыты 2GIS — актор не определяет
  для них регион. Нужен другой источник (Яндекс.Карты, ЕГРЮЛ по ОКВЭД 69.20).
- **Заринск** в 2GIS почти пуст: выдача сваливается на Барнаул, найдена
  одна организация.
- **Сегмент B даёт ~4% попаданий**: из ~170 обойдённых сайтов компаний
  отдельный адрес бухгалтерии нашёлся у шести. Расширение B — это линейное
  увеличение числа обходимых компаний.
- **Сегмент A ограничен источником**: на Avito, Профи.ру и HeadHunter email
  скрыт платформой. Открытые адреса физлиц-бухгалтеров встречаются только
  на личных сайтах и в карточках микропрактик.
- Поддомены вида `*.tilda.ws` схлопываются до корневого домена — одна запись
  в базе помечена как неподтверждённая по принадлежности.
