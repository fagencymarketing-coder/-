# База email бухгалтеров — Алтайский край

Сегментированная B2B-база email, собранная через Apify.

## Сегменты

- **A** — частные бухгалтеры (физлица, ИП, фрилансеры), email принадлежит конкретному человеку
- **B** — бухгалтерии компаний (штатные бухгалтеры, главбухи, финотделы), маркеры `buh@`, `glavbuh@`, `buhgalteria@`, `accounting@`, `finance@` либо явная подпись роли
- **C** — бухгалтерские компании на аутсорсе, аудиторские и консалтинговые фирмы, франчайзи 1С

## Пайплайн

1. **Сбор организаций** — Apify actor `zen-studio/2gis-places-scraper-api`
   по рубрикам «бухгалтерские услуги», «аутсорсинг бухгалтерии»,
   «аудиторские услуги», «налоговый консультант».
2. **Добыча email с сайтов** — Apify actor `poidata/contact-details-scraper`
   по доменам из шага 1. Даёт втрое больше адресов, чем один только 2GIS.
3. **Классификация и очистка** — `build.py`: раскладка по A/B/C,
   дедупликация по email, стоп-лист, выгрузка в xlsx.
4. **Разметка качества** — `refine.py`: колонки «Качество» (ядро / спорная)
   и «Осн. контакт» (да / нет), лист «Сводка».

## Правила отбора

- Email берётся только в явном виде с открытой страницы. Конструирование
  по маске (`info@` + домен) запрещено.
- Каждая запись имеет прямую ссылку на источник и попадает ровно в один сегмент.
- При сомнении — пометка `(?)` и наиболее вероятный сегмент.
- Исключаются: ФНС и органы власти, федеральные сервисы без местного офиса,
  записи без email.
- Дедупликация по email, домену и названию организации.

## Разметка качества

Колонка «Качество» отделяет твёрдые записи от требующих ручной проверки,
колонка «Осн. контакт» — первый адрес организации от последующих.

| Срез | Записей |
|---|---|
| Вся база | 52 |
| Без спорных (`Качество = ядро`) | 42 |
| Один контакт на компанию (`Осн. контакт = да`) | 45 |
| Твёрдое ядро (оба условия) | 36 |

Уникальных организаций в базе — 43.

## Статус

Пилот по Барнаулу: A=2, B=0, C=50. Стоимость прогона ~$0.58.

Известные ограничения:

- Кириллические домены (`.рф`) и поддомены (`*.tilda.ws`) вернули пустой
  результат — `poidata/contact-details-scraper` не справляется с punycode.
  Лечится сменой на `vdrmota/contact-info-scraper` или подачей домена в кириллице.
- Сегмент B пуст: пилот охватывал только рубрику бухуслуг, где живут A и C.
  Для B нужен отдельный заход по широким рубрикам (производство, УК/ТСЖ,
  юрфирмы, торговля, НКО) с фильтром по маркерам бухгалтерии.
